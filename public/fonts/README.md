# Command Center Fonts

Unmodified fonts used by the legacy dashboard, self-hosted here for its Next.js
UI. Do not subset, convert, or alter the Satoshi binaries.

- Satoshi regular/medium/bold: Indian Type Foundry / Fontshare.
  Source: https://api.fontshare.com/v2/css?f[]=satoshi@400,500,600,700&display=swap
  License: `FFL.txt`, from the official Satoshi download archive (FFL v2.0).
  Source archive: https://api.fontshare.com/v2/fonts/download/satoshi
- JetBrains Mono bold: JetBrains, SIL Open Font License, `JetBrainsMono-OFL.txt`.
  Source: https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;600;700&display=swap
  License source: https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt

Satoshi is included solely for this application's own UI, not as a font library
or user-selectable content font. Review its redistribution restrictions before
publishing the repository as a public template or font package.
